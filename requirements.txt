# Nothing to install for collecting.
#
# The parts that matter deliberately use only the Python standard library —
# urllib for HTTP, csv for the spool, and hand-built SVG for the charts. A
# server that only runs the pollers needs nothing but Python, because a poller
# that cannot reach the database writes to data/*.csv instead and replays later.
#
# Charting a CSV by hand needs nothing either:
#
#     python3 -m twitchmetrics graph data/metrics_yourchannel.csv
#
# Charting a CHANNEL reads the database, and that needs psycopg.
#
# Reading and writing the sample database is one exception:
#
#     pip install 'psycopg[binary]'   # or: pip install -e '.[pg]'
#
# It is imported lazily, so a machine that only collects still needs nothing: a
# poller whose database is unreachable appends to data/*.csv exactly as it
# always did, and replays the gap when it comes back. Only `graph`, `daily` and
# `db` require it.
#
# Publishing the daily report to S3 is the other:
#
#     pip install boto3            # or: pip install -e '.[aws]'
#
# It is imported lazily, so the whole CLI works without it — only `daily` and
# `s3` will tell you to install it.
#
# All you need on a server is Python 3.9 or newer:
#
#     python3 --version
#
# To install the `twitch-metrics` command itself:
#
#     pip install -e .
#
# Or skip installing entirely and run it in place:
#
#     python3 -m twitchmetrics --help
#
# Optional, and no longer used by anything — the website serves SVG, which
# browsers render natively. Only for turning a chart into a PNG by hand:
#
#     macOS         brew install librsvg
#     Debian/Ubuntu apt install librsvg2-bin
#     then          rsvg-convert -w 1600 charts/chart_x.svg -o chart.png
